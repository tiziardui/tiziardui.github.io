# Tiziano Arduini — academic website

Static two-page academic website for GitHub Pages.

## Structure
- `index.html`: profile, working papers, research in progress, publications, earlier research
- `teaching.html`: teaching
- `styles.css`: responsive design
- `favicon.svg`
- `profile-placeholder.svg`
- `robots.txt`
- `sitemap.xml`

## Deploy on GitHub Pages
Upload all files to the root of the public repository `tiziardui.github.io`, replacing the existing versions when prompted.

Then use **Settings → Pages → Deploy from a branch → main → /(root)**.

# Tiziano Arduini — academic website

Static two-page academic website ready for GitHub Pages.

## Structure
- `index.html`: profile, working papers, research in progress, publications, earlier research
- `teaching.html`: teaching
- `styles.css`: responsive design
- `favicon.svg`
- `robots.txt`

## Deploy on GitHub Pages
1. Create a public repository (for a personal site, typically `<username>.github.io`).
2. Upload these files to the repository root.
3. In **Settings → Pages**, deploy from the main branch/root.
4. After the final domain is known, add a canonical URL and a `sitemap.xml`, then submit it in Google Search Console.

## Before final launch
- Replace the CV link if a newer CV exists.
